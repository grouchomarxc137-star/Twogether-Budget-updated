How to use this workbook

  1. Enter each visit in Trip Log.
  2. Monthly Overview updates automatically from the Start date.
  3. Edit the yellow cells here to test renting and car scenarios.
  4. Click any editable money cell and use the formula bar if you want Excel-like formulas.
